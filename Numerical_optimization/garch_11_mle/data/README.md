# Data provenance

The core experiment uses a fully specified synthetic Gaussian GARCH(1,1) data-generating process. This avoids a runtime network dependency and, more importantly, makes parameter recovery measurable because the true parameters and latent conditional variance are known.

Running `scripts/run_experiment.py` creates `synthetic_garch11_returns.csv` with:

- seed: `2026`;
- observations: `4000` after a `1000`-observation burn-in;
- parameters: `mu=0.02`, `omega=0.05`, `alpha=0.08`, `beta=0.88`;
- Gaussian innovations generated by NumPy's `default_rng`;
- returns expressed in percentage units;
- columns: `time`, `return_percent`, and `true_variance`.

Simulation reproduces a specified model; it does not validate the model assumptions for real financial returns. A real-data extension should therefore record source, retrieval date, transformation and checksum, and should describe Gaussian estimation as QMLE when conditional normality is not assumed.
