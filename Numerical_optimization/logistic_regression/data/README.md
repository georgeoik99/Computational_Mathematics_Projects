# Budworm dose–mortality data

Twenty male and twenty female tobacco budworms were exposed at each of six doses (1, 2, 4, 8, 16, and 32 micrograms) of the pyrethroid insecticide *trans*-cypermethrin. `killed` and `alive` are grouped binary counts; the 12 rows represent 240 Bernoulli outcomes.

Source values: official R/MASS `dose.p` example, https://stat.ethz.ch/R-manual/R-devel/RHOME/library/MASS/html/dose.p.html

Additional documentation: CRAN `GLMsData`, https://stat.ethz.ch/CRAN/web/packages/GLMsData/GLMsData.pdf
