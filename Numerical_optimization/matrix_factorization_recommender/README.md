# MovieLens data

The notebook downloads `ml-latest-small` from the official GroupLens archive at `https://files.grouplens.org/datasets/movielens/ml-latest-small.zip`, uses the ratings and movies tables, and fixes the random seed and train/test split. The dataset is real user-item ratings; it is not generated by the notebook. The URL and retrieval code are kept in the notebook so the source is explicit.
